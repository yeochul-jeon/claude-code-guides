## 주요 의사결정

### 1. Stage 2+3 통합 실행

Stage 2(갭 합성)를 별도 단계로 분리하지 않고, 이전 세션 서머리에 에이전트 결과가 충분히 담겨 있어 Stage 3 문서 작성 과정에서 인라인으로 합성.
이유: 재분석 에이전트를 추가로 띄울 경우 비용·시간 중복. 서머리에서 10개 에이전트 결과가 구조화돼 있어 직접 합성 가능.

### 2. P0/P1/P2 분류 기준 확정

- **P0**: 대응 가이드 자체가 없는 무매칭 3건 → 신규 가이드 필요
- **P1**: 가이드는 있으나 원본 내용이 얕거나 누락 → 보강
- **P2**: 수치·사례·최신화 여지 있으나 우선순위 낮음 → 선택적

### 3. 선행 서베이 중복 회피

`RESEARCH_20260402_harness-survey.md`가 이미 하네스 기초·Anthropic Best Practices를 광범위하게 커버 → 갭 분석에서 해당 내용은 "중복" 섹션에 명시만 하고 재서술하지 않음.
