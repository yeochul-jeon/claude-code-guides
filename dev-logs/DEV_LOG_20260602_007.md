### 1. 검증 게이트 먼저 — Y-커맨드는 공식 문서 확인 후 작성

결과: `/bg`, `/ultraplan`, `/deep-research`, `/goal`, `/btw`, `/batch`, `/team-onboarding`, `/rewind`, `/powerup`, `/radio` 전부 공식 목록에서 확인됨.  
`/deepresearch`는 공식 표기가 `/deep-research`(하이픈 포함)임을 재확인.

### 2. 대부분 이미 통합되어 있음 — 감사가 핵심 작업

예상과 달리 22개 항목의 **20개가 이미 가이드에 통합**되어 있었다.  
`개인설정-가이드.md` §12 "고급 실행 모드"가 Y-커맨드 대부분의 허브 역할을 하고 있었고,  
`cross-agent-워크플로우.md`, `하네스-엔지니어링-방법론.md`, `harness-추천구성.md` 등에도 S-항목이 분산 반영되어 있었다.

→ 실제 신규 추가 작업: 2개 (`/btw` → 10단계, `--permission-mode auto` → 팀-IDE-통합-가이드)  
→ 나머지 20개는 존재 확인 + 완료 상태 기록.

### 3. Ultra Review 과금 단가($5/회) 미반영

P1-Y6 "Ultra Review ~$5/회"는 youtube 소스 §5 "미확정 항목"에 명시된 미검증 수치.  
공식 문서에는 "Pro/Max 3회 무료 후 usage credits"만 있고 구체 단가 없음.  
→ 미확정 수치이므로 가이드에 기재하지 않음. 현재 `cross-agent-워크플로우.md`의 "3회 무료 후 usage credits" 표현이 적절.

## 대화 중 주요 논의

### "이미 통합된 항목이 많다" — 감사 우선 접근의 가치

세션 시작 시 22개를 모두 새로 작성해야 한다고 가정했으나, 감사 결과 20개가 이미 통합되어 있었다.  
이는 `개인설정-가이드.md` §12 "고급 실행 모드"가 6~7월 세션에 걸쳐 누적 보강된 결과였다.  
감사 없이 재작성했다면 중복 및 내용 불일치가 발생할 수 있었다.

**교훈**: 백로그 항목 통합 전 grep 기반 전수 감사를 먼저 수행하는 것이 필수. 특히 10개 이상 파일이 관련될 때.

### Advisor 게이트: 검증 없는 ASR 기반 커맨드 기재 위험

`/voice` 오기 선례가 있으므로 Y-커맨드를 공식 문서 확인 전에 작성하지 않기로 결정.  
Ultra Review 단가($5/회)도 미확정으로 분류하여 기재 제외.  
이 "검증 게이트 우선" 원칙은 향후 커뮤니티 자료 기반 백로그 작업에도 동일 적용한다.
