## 주요 의사결정

### 1. 신규 가이드 vs 기존 가이드 확장

**선택지**:
- A) 신규 가이드 `claude-code-CLAUDE-md-반복개선-루프.md` 신설
- B) 기존 `실전-작성법.md`에 §9 추가
- C) 하이브리드: 신규 가이드 + 실전-작성법에 크로스링크만

**결정**: C 하이브리드.  
이유: 반복 개선 루프는 "작성 방법"과 명확히 다른 독자층을 대상으로 한다(신규 프로젝트 설정자 vs 기존 CLAUDE.md 유지보수자). 실전-작성법.md는 이미 32KB로 크기 때문에 내용을 더 넣으면 인식 부담이 높아진다. 크로스링크로 진입점만 제공하는 것이 최선이었다.

### 2. 신규 가이드의 범위 결정

**포함**:
- 반복 개선 루프 3단계 (Observe → Improve → Verify)
- `claude-md-improver` 스킬 5단계 워크플로 + 채점 루브릭
- `#` 단축키 (신규 발굴 — 기존 가이드 어디에도 없었음)
- Staleness 감지 기준
- Progressive Disclosure (@import 분리 전략)

**제외**:
- 작성법·템플릿 — 실전-작성법.md로 링크만
- 비용효율 메트릭 — 비용효율-측정 가이드로 링크만

### 3. Plan Mode 활용

사용자가 플랜 승인을 요청하는 흐름이어서 Plan Mode에서 갭 분析·산출물 정의까지 완료 후 승인을 받은 뒤 실행했다.  
이전 세션 플랜 파일(YouTube 분析 플랜)이 같은 경로에 남아 있어 Write로 전면 교체했다 (Edit old_string 매칭 실패 → Write로 우회).

## 대화 중 주요 논의

### claude-md-improver 스킬의 `#` 단축키 발굴

SKILL.md 분석 중 `#` 단축키(세션 중 학습 내용을 CLAUDE.md에 즉시 반영)가 기존 가이드 17편 어디에도 없음을 확인했다. 실전-작성법의 §8 진단 체크리스트는 "무엇을 넣고 뺄지" 판단 도구였고, `#` 단축키는 "언제 즉시 넣는가"의 실행 도구 — 완전히 별개 주제로 신규 가이드에 독립 섹션으로 포함했다.

### Plan Mode와 플랜 파일 충돌 처리

이전 세션의 YouTube 분析 플랜이 같은 플랜 파일 경로에 남아 있었다. Edit으로 교체를 시도했으나 한글 인코딩 불일치로 `old_string not found` 오류 발생. 이 경우 Write로 전체 교체가 안전한 우회책임을 재확인했다.
