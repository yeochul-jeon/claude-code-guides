## 작업 배경

세션9까지 가이드 신설·보강이 집중적으로 이루어졌으나 README.md 문서 목록이 동기화되지 않았다.  
사용자가 README 링크 점검을 요청해 실제 `guides/`에 존재하는 파일과 README의 링크를 대조했다.  
결과: 기존 링크 12개는 전부 유효했으나, **실제 파일 18개 중 6개가 README에서 누락**된 상태였다.

## 주요 의사결정

### 1. 누락 6개를 어디에 배치할 것인가

**선택지**:
- A) 모두 기존 번호 학습 경로 테이블에 삽입
- B) 일부만 학습 경로 삽입 + 나머지는 별도 섹션
- C) 전부 별도 "심화" 섹션

**결정**: B (하이브리드).

**근거**: 6개 중 2개(초보자 튜토리얼, 반복 개선 루프)는 학습 순서상 명확한 위치가 있어 번호 테이블에 삽입이 자연스럽다. 나머지 4개(시스템 프롬프트, 모델별 프롬프팅, 비용효율, LLM-Wiki)는 순서 무관 주제별 심화 가이드로, 번호 테이블에 끼우면 번호 체계의 의미가 희석된다. 별도 "심화·확장 가이드" 섹션으로 묶으면 독자가 학습 경로와 레퍼런스 참조를 명확히 구분할 수 있다.

### 2. 삽입 번호 선택

- `초보자-튜토리얼.md` → `0.5`: Quick Start(0) 바로 뒤. 설치 후 전체 흐름 핸즈온이므로 입문 시퀀스에 속함.
- `CLAUDE-md-반복개선-루프.md` → `3.3`: 실전 작성법(3) 바로 뒤. "작성 후 개선"은 작성법의 자연스러운 연장이고, 기존 3.5(통제센터)와 순서가 겹치지 않음.
